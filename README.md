## 🕹️ Overview

Daily OVR displays a customizable information dashboard in VR showing the time, weather, calendar events, and news so you stay informed without leaving VR.

Whether you're a newcomer or a veteran, Daily OVR provides the tools you need to get the most out of your gaming tools experience. Designed for Windows and macOS, it delivers a seamless, high-performance workflow.

## ✨ Key Features

| **Calendar Integration** | Syncs with Google Calendar to show upcoming events |
| **News Feed** | Configurable RSS feeds displayed as readable VR cards |
